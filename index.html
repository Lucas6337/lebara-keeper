三重防缓存机制

1. 动态 URL 参数
每次请求拼接时间戳与随机串 payload.txt?t=...&r=...，绕过浏览器与 CDN 缓存。
2. HTTP 不缓存指令
使用 cache: 'no-store' 与 Cache-Control: no-cache, no-store 请求头。
3. 不可压缩随机载荷
payload.txt 为约 150 KB 随机字符，即使经过服务器 gzip 压缩仍约有 115 KB 实际传输量。若文件缺失会直接报错，不会静默回退。

生成与部署步骤

1. 生成 payload.txt（约 150 KB）
macOS / Linux：openssl rand -base64 115000 > payload.txt
2. 上传 Cloudflare Pages（国内直连推荐）
  1. 登录 Cloudflare Dashboard → Workers & Pages → Create → Pages → Upload assets。
  2. 上传包含 index.html 与 payload.txt 的文件夹。
  3. 通过生成的 *.pages.dev 链接访问即可。
